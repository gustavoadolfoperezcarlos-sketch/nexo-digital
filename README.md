# Nexo Digital

Portafolio comercial construido con Next.js, TypeScript y Tailwind CSS.

## Desarrollo local

```bash
npm install
npm run dev
```

## Antes de publicar

- Configurar `RESEND_API_KEY`, `CONTACT_TO_EMAIL` y `CONTACT_FROM_EMAIL` en Vercel.
- Sustituir los textos provisionales por información comercial validada.
- Añadir política de privacidad y datos de contacto.
- Conectar el repositorio de GitHub con Vercel.
